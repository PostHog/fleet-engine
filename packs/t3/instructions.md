## T3 Code

T3 Code runs my threads on this machine.

- When you need a secret from me, ask for it with T3's `request_secret` tool.
- T3 Code folds the text you write between tool calls, so put each question for me in your final message or in the question tool.
- **T3**, `~/.agents/guides/t3.md`: read it before you launch a thread or hand off a side fix, reach a thread on another machine, or switch a thread's model.
